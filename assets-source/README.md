# assets-source

앱에 들어간 이미지의 **원본** 을 보관하는 곳이다.
앱이 실제로 쓰는 파일은 `apps/mobile/assets/` 에 있다. 여기 있는 것은 그 재료다.

원본을 남기는 이유: 아이콘 크기나 잘라내는 범위를 다시 조정해야 할 때
원본이 없으면 이미 가공된 파일을 또 가공하게 되어 화질이 떨어진다.

| 파일 | 쓰임 | 가공 결과 |
|---|---|---|
| `icon-original.png` | 앱 아이콘 | `apps/mobile/assets/icon.png` |
| `onboarding-bg-original.png` | 첫 화면 배경 | `apps/mobile/assets/onboarding-bg.png` |

## 가공 방법

**아이콘** — 원본은 모서리가 둥글게 깎이고 바깥이 투명하다.
iOS 아이콘은 정사각형이어야 하고 투명을 허용하지 않으며, 모서리는 OS 가 직접 깎는다.
그래서 둥근 사각형 **안쪽 930x930 만 잘라내** 1024x1024 정사각형으로 만들고 알파 채널을 제거했다.

안드로이드 적응형 아이콘은 앞면 층의 가운데 66% 만 안전 영역이라 사진을 넣으면 확대되어 잘린다.
그래서 하늘 이미지는 **배경 층**(`android-icon-background.png`)에 넣고 앞면은 투명하게 비웠다.

## 규칙

- 파일 이름에 **한글과 공백을 쓰지 않는다.** iOS 빌드가 깨진다. (`docs/DEVELOPMENT.md`)
- 새 이미지를 추가하면 이 표에 한 줄 적는다.
